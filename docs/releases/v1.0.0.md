# ChatCord v1.0.0

Released on 2 November 2026.

ChatCord v1.0.0 is the first complete educational-project milestone. It brings the implemented authentication, room, social, messaging and realtime workflows together with a tested local Docker environment and current documentation.

## Included

- Google-backed registered accounts, username onboarding, profile editing and server-side sessions.
- Fixed 30-minute guest identities with public-room discovery, joining and chat.
- Public/private groups, invitations, membership roles and permission controls.
- Friend requests, friend-only direct messages and retained eligible history after unfriending.
- Persistent messages with paging, editing, deletion placeholders, replies, reactions and scoped search.
- Join-time history boundaries and trusted room-activity notices.
- Socket.IO messages, reconnect reconciliation, presence and typing backed by Redis.
- Responsive workspace, Notifications, Settings, public privacy/terms pages and route-level splitting.
- Client/server Docker images, private MongoDB/Redis services, health checks, named volumes, live-reload development mode and an isolated smoke script.
- Consolidated architecture, module guides and verification documentation.

## Verification snapshot

- 129 backend controller tests across six suites.
- 27 real MongoDB/Redis workflows with scoped Socket.IO checks.
- 79 frontend behavior tests across 15 files.
- TypeScript, ESLint, architecture boundaries, production build and bundle checks passed.
- Built/development Docker stacks, HTTP/session proxying, guest discovery/join/send, WebSocket delivery, reload persistence and source reload passed.

The verification details and dates are recorded in the [project README](../../README.md#verification).

## Known limits

This branch is a versioned project milestone, not a claim that a public hosted service is operationally ready. Before public deployment, complete real-origin Google OAuth verification, HTTPS/cookie/proxy review, CI, broader browser/accessibility coverage, monitoring/logging, index and backup/restore checks, and the operator-specific privacy/retention/contact details listed in the README.

Attachments, profile uploads, ownership transfer, blocking/reporting, account export/deletion and durable unread notifications are not included.

## Upgrade notes

This is the first versioned milestone, so there is no previous release migration. Existing local MongoDB data is retained by Docker named volumes. Review environment values before starting the stack; do not run the disposable smoke project against development data.
